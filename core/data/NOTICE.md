# Recipe data

`src/main/assets/recipes/java.json` lists crafting recipes, item tags and English item names from
**Minecraft: Java Edition 26.3** (client jar sha1 `e877b6a07acd633fb3bb475002175cec036e7b87`), generated on
**2026-10-20** by `scripts/recipes/generate_recipes.py`. Minecraft and its data are © Mojang AB / Microsoft. Only
facts derived from the game's data (which items a recipe takes, how many it makes, and item names) are stored; no
game file is included. WikiDroid is an unofficial app, not affiliated with Mojang or Microsoft.

Item icons are loaded at runtime from [minecraft.wiki](https://minecraft.wiki) (`File:Invicon_<Name>.png`), which
shares them under [CC BY-NC-SA 3.0](https://creativecommons.org/licenses/by-nc-sa/3.0/). About credits both.
